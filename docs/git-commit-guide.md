# Git Commit Guide

## Common Types

### chore

Project setup, configuration, tooling changes.

Examples:

```bash
git commit -m "chore: initialize Next.js blog project"
git commit -m "chore: configure ESLint"
```

### feat

New features.

Examples:

```bash
git commit -m "feat: create homepage"
git commit -m "feat: add blog list page"
```

### fix

Bug fixes.

Examples:

```bash
git commit -m "fix: correct article routing"
```

### docs

Documentation updates.

Examples:

```bash
git commit -m "docs: update README"
git commit -m "docs: add learning log"
```

### refactor

Code restructuring without changing behavior.

Examples:

```bash
git commit -m "refactor: extract post card component"
```
