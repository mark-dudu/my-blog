# My Blog

个人技术博客项目。

## Goals

* 记录学习过程
* 输出技术文章
* 构建长期维护的个人作品集
* 为后续更复杂项目积累经验

## Tech Stack

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS
* pnpm

## Development

```bash
pnpm install
pnpm dev
```
